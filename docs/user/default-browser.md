# Use Ada as your default browser

On macOS, you can set the Ada desktop app as your default web browser so links from other apps and local HTML files open directly in Ada.

## Enable

Choose **Ada** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

- If the active thread has its browser panel open, the link opens as a new tab there; otherwise Ada opens a new no-project thread with the browser panel maximized so you can ask an agent about the page right away.
- Pull request links for connected projects open in the PR view (when **Open pull requests in Ada** is enabled).
